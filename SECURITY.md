# Security policy

## Reporting a vulnerability

Please do not disclose vulnerability details in a public issue. After the repository is published, use its Security tab if private vulnerability reporting is enabled. Otherwise, ask the repository owner for a private contact channel without disclosing the vulnerability. No private reporting channel is configured in this local repository yet.

Include the affected version, a minimal reproduction, impact, and a suggested mitigation when possible. Remove API keys, access tokens, repository contents, and personal data from all reports.

Maintainer-Zero is a local, heuristic analyzer. It does not upload repository content, but callers remain responsible for reviewing generated artifacts before sharing them.
