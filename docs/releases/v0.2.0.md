# Maintainer-Zero v0.2.0: alpha preview

If your core maintainer were unavailable for 90 days, what would block the next security fix?

Maintainer-Zero reads a local Git checkout and models maintainer absence, dependency yanks,
and CI/release outages. It produces an explainable heuristic score, a simulated incident
timeline, and recovery drafts you can review.

## Try it

Python 3.10+ and Git are required. No runtime package dependencies or token are needed:

```sh
git clone --branch v0.2.0 https://github.com/LittleChenLiya/maintainer-zero.git
cd maintainer-zero
python -m maintainer_zero demo --fail-on-regression
python -m maintainer_zero simulate . --scenario all --output .continuity
```

Use `python3` if needed. Open `.continuity/report.html` and review
`.continuity/recovery/runbook.md`. The bundled before/after demos use synthetic data,
not results from production projects.

You can also install the attached wheel in a Python virtual environment:

```sh
python -m pip install --no-deps https://github.com/LittleChenLiya/maintainer-zero/releases/download/v0.2.0/maintainer_zero-0.2.0-py3-none-any.whl
maintainer-zero demo --fail-on-regression
```

Downloading source or a wheel uses the network; the demo and default analysis run offline.
This is a GitHub pre-release with package version `0.2.0`, not a PyPI or Marketplace release.

## Included

- Deterministic incident models, explicit assumptions, and JSON/Markdown/HTML reports.
- Baseline regression gates, local score history, and a reusable composite GitHub Action.
- Review-only Runbook, CODEOWNERS, Issue, PR-comment, and SARIF drafts.
- Data-only scenario validation and explicitly authorized, read-only metadata collection
  for GitHub, GitLab, and Forgejo.

## Limits

This is an alpha MVP. Scores are heuristics, not security certification, incident
probabilities, cross-project rankings, or proof of real disaster recovery. The tool does
not run project builds, disable services, or automatically write to GitHub. Recovery
actions are drafts, not executed repairs.

It is offline by default. Optional metadata collection requires explicit network opt-in
and separate consent to load environment credentials. Reports can still expose dependency
names and findings; inspect them before sharing. Artifact manifests and integrity
credentials check content integrity, not digital signatures or publisher identity.
