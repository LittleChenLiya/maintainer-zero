# Maintainer-Zero v0.2.2: traceable read-only transports

This alpha patch keeps the opt-in GitHub, GitLab, and Forgejo HTTP transports
explicitly read-only while synchronizing their default User-Agent strings with
the package version. Audit logs can now identify the client release instead of
silently reporting the previous version.

The copy-paste consumer workflow remains pinned to an immutable reviewed commit
and validates the report, manifest, and integrity credential offline before it
uploads artifacts.

## Boundaries

Maintainer-Zero is an alpha, offline-first heuristic tool. It does not provide
security certification, prove real disaster recovery, execute repairs, or write
to GitHub. The integrity credential checks content integrity, not signatures or
publisher identity. This is a GitHub pre-release, not a PyPI or Marketplace
release.
