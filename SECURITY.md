# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for this repository, or contact the maintainers privately through the address listed in the repository profile.

Include the affected version, a minimal reproduction, impact, and a suggested mitigation when possible. Remove API keys, access tokens, repository contents, and personal data from all reports.

Maintainer-Zero is a local, heuristic analyzer. It does not upload repository content, but callers remain responsible for reviewing generated artifacts before sharing them.
