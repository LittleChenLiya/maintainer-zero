# Support

Maintainer-Zero is an alpha, offline-first project. Start with the [README](README.md), the
[中文使用指南](docs/GUIDE_ZH.md), and the [demo guide](docs/DEMOS.md) before opening a request.

## Questions and ideas

Use [GitHub Discussions](https://github.com/LittleChenLiya/maintainer-zero/discussions) for usage
questions, benchmark comparisons, scenario proposals, and roadmap ideas. Include the command,
Maintainer-Zero version, Python version, and operating system when they affect the behavior.

## Bugs

Use the [bug report form](https://github.com/LittleChenLiya/maintainer-zero/issues/new?template=bug_report.yml).
Provide a minimal sanitized fixture or public repository and the exact command. Generated reports
can contain repository-sensitive dependency names or findings, so review and redact them before
sharing.

## Scenario proposals

Use the [scenario proposal form](https://github.com/LittleChenLiya/maintainer-zero/issues/new?template=scenario.yml).
Scenarios must be declarative and data-only: do not include commands, scripts, tokens, secrets, or
unredacted private repository data.

## Security and privacy

Read the [security policy](SECURITY.md) before reporting a vulnerability or privacy issue. Never
put credentials or private repository content in a public issue or Discussion.

## Community conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in Issues, Discussions, and pull
requests. Conduct concerns should be reported privately; do not include sensitive details in a
public thread.
