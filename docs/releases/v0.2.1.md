# Maintainer-Zero v0.2.1: Action contract patch

This alpha patch publishes the `action-path` output used by the copy-paste
consumer workflow. It lets a later step run the bundled offline validators
without a second checkout or a build step.

## Try the consumer workflow

Copy [examples/consumer-workflow.yml](../../examples/consumer-workflow.yml) into
`.github/workflows/maintainer-zero.yml` in a repository you control. Review the
immutable commit pin, keep `contents: read`, and inspect the generated report
before sharing it. The workflow validates the report, manifest, and credential
offline before uploading artifacts.

## Boundaries

This remains an alpha, offline-first heuristic tool. It does not certify
security, prove real disaster recovery, execute repairs, or write to GitHub.
The integrity credential checks content integrity, not signatures or publisher
identity.

The package is published as a GitHub pre-release only; it is not a PyPI or
Marketplace release.
